# Seedance 2.5 视频生成

Cloubic 已支持 Seedance 2.5 视频模型。通过统一的视频生成接口，可以发起文生视频、图生视频和参考素材生视频任务。{{ className: 'lead' }}

<Note>
  视频生成是异步任务。提交请求后请保存返回的任务 ID，并轮询任务查询接口获取最终视频。
</Note>

---

## 支持模型

<Properties>
  <Property name="doubao-seedance-2-5-260628" type="model">
    根据输入素材自动选择文生视频、图生视频或参考素材生视频。
  </Property>
</Properties>

自动模式的选择规则：没有媒体素材时使用文生视频；只有首尾帧图片时使用图生视频；存在参考图片、视频或音频时使用参考素材生视频。

## 图生视频

使用 `bytedance/seedance/2.5/image-to-video` 时，至少提供一张图片，最多提供两张。推荐使用 `content` 明确指定 `first_frame` 和 `last_frame`：

```json
{
  "model": "bytedance/seedance/2.5/image-to-video",
  "prompt": "镜头缓慢向前推进，人物转向窗边的光线",
  "duration": 6,
  "resolution": "480p",
  "generate_audio": false,
  "content": [
    {
      "type": "image_url",
      "role": "first_frame",
      "image_url": {"url": "https://example.com/first-frame.jpg"}
    },
    {
      "type": "image_url",
      "role": "last_frame",
      "image_url": {"url": "https://example.com/last-frame.jpg"}
    }
  ]
}
```

使用两张图片时建议始终显式设置角色。图生视频不会向上游转发 `ratio` 参数，也不能混入参考视频或参考音频。

## 参考素材生视频

使用 `bytedance/seedance/2.5/reference-to-video` 时，可传入参考图片、参考视频或参考音频。音频不能单独使用，至少还需要一张图片或一个视频。

```json
{
  "model": "bytedance/seedance/2.5/reference-to-video",
  "prompt": "保持角色外观一致，让角色在现代城市街道中向前行走",
  "duration": 10,
  "resolution": "720p",
  "ratio": "9:16",
  "generate_audio": true,
  "content": [
    {
      "type": "image_url",
      "role": "reference_image",
      "image_url": {"url": "https://example.com/character.png"}
    },
    {
      "type": "video_url",
      "role": "reference_video",
      "video_url": {"url": "https://example.com/motion.mp4"}
    },
    {
      "type": "audio_url",
      "role": "reference_audio",
      "audio_url": {"url": "https://example.com/voice.wav"}
    }
  ]
}
```

### `content` 角色

| 类型 | `role` | 说明 |
| --- | --- | --- |
| `image_url` | `first_frame` | 图生视频首帧 |
| `image_url` | `last_frame` | 图生视频尾帧 |
| `image_url` | `reference_image` | 参考图片 |
| `video_url` | `reference_video` | 参考视频，最多 10 个 |
| `audio_url` | `reference_audio` | 参考音频 |

## 参数说明

### `metadata`

`metadata` 可以是对象，也可以是 JSON 字符串。支持以下兼容字段：

| 字段 | 说明 |
| --- | --- |
| `resolution` | `resolution` 的兼容来源 |
| `duration` | `duration` 的兼容来源 |
| `generate_audio` | `generate_audio` 的兼容来源 |
| `ratio` / `aspect_ratio` | 宽高比的兼容来源 |
| `video_url` | 无 `content` 时提供参考视频 |
| `audio_url` | 无 `content` 时提供参考音频 |

参数优先级为请求顶层字段，其次是 `metadata`，最后使用默认值。

## 下载视频

任务完成后，可通过任务 ID 获取视频文件流：

```bash
curl 'https://api.cloubic.com/v1/videos/{task_id}/content' \
  -H "Authorization: Bearer YOUR_API_KEY" \
  --output video.mp4
```

该接口成功时直接返回 `video/mp4` 二进制内容，不返回 JSON。

## 常见限制

- 图片、视频和音频必须使用公网可访问 URL 或 data URI；不支持依赖 multipart 文件字段上传本地文件。
- 文生视频必须提供非空提示词，且不能携带媒体素材。
- 图生视频最多使用两张图片；使用两张图片时建议设置首帧和尾帧角色。
- 当前支持 `480p`、`720p`，暂不支持 `1080p`。
- 当前不支持取消任务、删除任务和 Webhook 回调。

## 常见错误

| 场景 | 错误信息 |
| --- | --- |
| 缺少输入 | `prompt, content, image or video is required` |
| 文生视频缺少提示词 | `prompt is required for text-to-video` |
| 音频单独使用 | `audio_url cannot be used alone` |
| 参考视频超过限制 | `reference video input cannot exceed 10 files` |
| 分辨率不支持 | `resolution must be one of 480p, 720p, 1080p` |
| 时长超出范围 | `duration must be between 4 and 30 seconds` |
