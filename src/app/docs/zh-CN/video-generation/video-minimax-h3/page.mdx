# MiniMax H3 视频生成

Cloubic 已支持 MiniMax H3 视频模型。通过统一的视频生成接口，可以发起文生视频、图生视频和参考素材生视频任务。{{ className: 'lead' }}

<Note>
  视频生成是异步任务。提交请求后请保存返回的任务 ID，并轮询任务查询接口获取最终视频。
</Note>

---

## 支持模型

<Properties>
  <Property name="MiniMax-H3" type="model">
    自动根据输入素材选择文生视频、图生视频或参考素材生视频。
  </Property>
</Properties>

自动模式会根据输入素材选择具体任务类型。

## 创建视频任务

<Row>
  <Col>
    <Endpoint method="POST" path="https://api.cloubic.com/v1/video/generations" />

    ### 请求头

    <Properties>
      <Property name="Authorization" type="string" required>
        Bearer Token，格式：`Bearer YOUR_API_KEY`
      </Property>
      <Property name="Content-Type" type="string" required>
        请求体格式，固定为 `application/json`
      </Property>
    </Properties>

    ### 请求参数

    <Properties>
      <Property name="model" type="string" required>
        模型 ID：`MiniMax-H3`
      </Property>
      <Property name="prompt" type="string" required>
        视频描述文本。也可以在 `content` 中传入 `text`，但最终必须得到非空提示词。
      </Property>
      <Property name="content" type="array">
        多模态内容数组，支持 `text`、`image_url`、`video_url` 和 `audio_url`。
      </Property>
      <Property name="duration" type="integer">
        视频时长，单位为秒，范围 `4` 到 `15`，默认 `5`。
      </Property>
      <Property name="resolution" type="string">
        输出分辨率，支持 `2K` 和 `768P`，默认 `2K`。
      </Property>
      <Property name="ratio" type="string">
        视频宽高比。文生视频支持 `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`；参考素材模式还支持 `adaptive`。
      </Property>
      <Property name="image" type="string">
        首帧图片 URL 或 data URI，兼容图生视频请求。
      </Property>
      <Property name="end_image" type="string">
        尾帧图片 URL 或 data URI，必须与首帧图片一起使用。
      </Property>
      <Property name="metadata" type="object">
        扩展参数。可传 `resolution`、`duration`、`ratio`、`aspect_ratio`，以及参考视频时长校验字段。
      </Property>
    </Properties>
  </Col>

```bash {{ title: 'cURL' }}
    "model": "MiniMax-H3",
    "prompt": "一片竹林中的小溪，阳光穿过树叶洒在水面上",
    "duration": 8,
    "resolution": "2K",
    "ratio": "16:9"
  }'
```

```python {{ title: 'Python' }}
url = 'https://api.cloubic.com/v1/video/generations'

    'model': 'MiniMax-H3',

    'ratio': '16:9',

response = requests.post(url, headers=headers, json=data)
```

## 图生视频

使用 `MiniMax-H3` 并传入首帧图片时，会执行图生视频任务；可选一张 `last_frame` 图片。推荐使用 `content` 明确指定图片角色：

```json
{
  "model": "MiniMax-H3",
  "prompt": "镜头从远景缓慢推进到人物面部，人物轻轻转头",
  "duration": 6,
  "resolution": "768P",
  "content": [
    {
      "type": "image_url",
      "role": "first_frame",
      "image_url": {"url": "https://example.com/first-frame.jpg"}
    },
    {
      "type": "image_url",
      "role": "last_frame",
      "image_url": {"url": "https://example.com/last-frame.jpg"}
    }
  ]
}
```

也可以使用兼容字段 `image` 和 `end_image`。图生视频不支持参考图片、参考视频和参考音频，也不使用宽高比参数。

## 参考素材生视频

使用 `MiniMax-H3` 并传入参考素材时，会执行参考素材生视频任务。至少提供一个参考图片、参考视频或参考音频；参考图片最多 9 张，参考视频和参考音频各最多 3 个，音频不能单独使用。

```json
{
  "model": "MiniMax-H3",
  "prompt": "保持角色外观和服装一致，让角色在城市街道中向前行走",
  "duration": 10,
  "resolution": "2K",
  "ratio": "adaptive",
  "content": [
    {
      "type": "image_url",
      "role": "reference_image",
      "image_url": {"url": "https://example.com/character.png"}
    },
    {
      "type": "video_url",
      "role": "reference_video",
      "video_url": {"url": "https://example.com/motion.mp4"}
    },
    {
      "type": "audio_url",
      "role": "reference_audio",
      "audio_url": {"url": "https://example.com/voice.wav"}
    }
  ]
}
```

### `content` 角色

| 类型 | `role` | 说明 |
| --- | --- | --- |
| `image_url` | `first_frame` | 图生视频首帧，最多 1 张 |
| `image_url` | `last_frame` | 图生视频尾帧，必须同时存在首帧 |
| `image_url` | `reference_image` | 参考图片，最多 9 张 |
| `video_url` | `reference_video` | 参考视频，最多 3 个 |
| `audio_url` | `reference_audio` | 参考音频，最多 3 个 |

## 下载视频

任务完成后，可通过任务 ID 获取视频文件流：

```bash
curl 'https://api.cloubic.com/v1/videos/{task_id}/content' \
  -H "Authorization: Bearer YOUR_API_KEY" \
  --output video.mp4
```

该接口成功时直接返回 `video/mp4` 二进制内容，不返回 JSON。

## 常见限制

- 图片、视频和音频必须使用公网可访问 URL 或 data URI；不支持依赖 multipart 文件字段上传本地文件。
- 文生视频不能携带图片、视频或音频素材。
- 图生视频的 `last_frame` 不能脱离 `first_frame` 单独使用。
- 参考素材模式不能混入 `first_frame` 或 `last_frame`。
- 当前不支持取消任务、删除任务和 Webhook 回调。

## 常见错误

| 场景 | 错误信息 |
| --- | --- |
| 缺少提示词 | `prompt is required` |
| 缺少模型 | `model field is required` |
| 图生视频缺少首帧 | `image-to-video requires first_frame image` |
| 参考素材为空 | `reference-to-video requires reference_image, reference_video or reference_audio` |
| 时长不合法 | `duration must be an integer from 4 to 15` |
| 分辨率不支持 | `resolution must be 2K or 768P` |
