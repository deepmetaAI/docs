# 豆包 Seedance 2.0 视频生成

Cloubic 目前已支持豆包 Seedance 2.0 系列视频生成模型的统一接入与调用。通过本章节提供的接口说明，您可以使用同一个视频生成接口发起文生视频、图生视频、视频参考、音频参考和多模态混合输入任务。{{ className: 'lead' }}

<Note>
  调用视频生成模型生成视频时，系统会返回一个任务
  ID；用户需要轮询查询接口获取任务状态和视频结果。
</Note>

## 支持模型

<Properties>
  <Property name="doubao-seedance-2-0-260128" type="model">

  </Property>
  <Property name="doubao-seedance-2-0-fast-260128" type="model">
    对应 `nova-video-2.0-fast`，快速版本，延迟更低，支持 480p、720p，不支持
    1080p。

## content 输入结构

`content` 是对象数组，每个元素必须包含 `type` 字段。支持的组合包括：

- 文本
- 文本（可选）+ 图片
- 文本（可选）+ 视频
- 文本（可选）+ 图片 + 音频
- 文本（可选）+ 图片 + 视频
- 文本（可选）+ 视频 + 音频
- 文本（可选）+ 图片 + 视频 + 音频

<Note>
  音频不能单独存在，必须配合至少一个 text、image_url 或 video_url 输入。
</Note>

<Properties>
  <Property name="type: text" type="object">
    文本提示词。格式：`{ "type": "text", "text": "一只小狗在阳光下的草地上奔跑" }`
  </Property>
  <Property name="type: image_url" type="object">
    图片输入。`image_url.url` 支持公网图片 URL，或 `data:image/...;base64,...` 内联 base64。`role` 可传 `first_frame`、`reference_image` 等。
  </Property>
  <Property name="type: video_url" type="object">
    视频输入。`video_url.url` 支持公网视频 URL。`role` 可传 `reference_video`。携带任一 `video_url` 即视为视频参考模式。
  </Property>
  <Property name="type: audio_url" type="object">
    音频输入。`audio_url.url` 支持公网音频 URL。`role` 可传 `reference_audio`。
  </Property>
</Properties>

  {
    "type": "audio_url",

## 状态枚举

<Properties>
  <Property name="queued" type="status">
    已排队等待处理，客户端继续轮询。
  </Property>
  <Property name="running / in_progress" type="status">
    正在生成，客户端继续轮询。
  </Property>
  <Property name="succeeded / completed" type="status">
    任务成功，可取 `data.url` 下载视频。
  </Property>
  <Property name="failed" type="status">
    任务失败，可读取 `data.error` 定位原因。
  </Property>
  <Property name="expired" type="status">
    任务超过 `execution_expires_after` 未完成，需要重新提交。
  </Property>
</Properties>

## 完整轮询示例

```bash
RESP=$(curl -sS -X POST "https://api.omnimaas.cn/v1/video/generations" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-fast-260128",
    "content": [
      { "type": "text", "text": "一个夕阳下的海边" }
    ],
    "ratio": "16:9",
    "resolution": "720p",
    "duration": 5
  }')

TASK_ID=$(echo "$RESP" | jq -r '.id // .task_id // .data.task_id')
echo "task_id=$TASK_ID"

while true; do
  RESP=$(curl -sS "https://api.omnimaas.cn/v1/video/generations/$TASK_ID" \
    -H "Authorization: Bearer YOUR_API_KEY")
  STATUS=$(echo "$RESP" | jq -r '.data.status // .status')
  echo "$(date +%T) status=$STATUS"
  case "$STATUS" in
    succeeded|completed)
      echo "$RESP" | jq -r '.data.url // .url // .content.video_url'
      break ;;
    failed|expired)
      echo "$RESP" | jq -r '.data.error // .error'
      break ;;
  esac
  sleep 10
done
```

## 注意事项

- 视频结果 URL 为临时签名地址，请尽快下载到自己的对象存储或 CDN，不要作为长期对外分发链接。
- 内容审核类失败（如 `INVALID_PROMPT`、`BLOCKED_BY_MODERATION`）通常不建议原样重试，请修改 prompt 或输入素材后重新提交。
- 建议每 10 到 30 秒轮询一次任务状态，生产环境可结合 `callback_url` 降低轮询压力。
- `audio_url` 不能单独作为唯一输入，必须配合文本、图片或视频。
- `ratio: "adaptive"` 会由模型根据输入素材自动选择比例，实际比例会在查询响应中回填。
- `image_url.url`、`video_url.url`、`audio_url.url` 需要公网可访问；大文件建议先登记到素材库后再引用。
